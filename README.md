# Blue Team Cybersecurity Portfolio & DFIR Writeup Showcase

An interactive, high-contrast, offensive/defensive cybersecurity portfolio and technical investigation dossier hub. Designed for SOC Analysts, Incident Responders, and Threat Hunters to showcase real-world forensics, CTF challenges, homelab SIEM architecture, and verifiable credentials.

This is the project I created during the Google Vibe-coding workshop at my university.

---

## 🎯 Features

- **Executive & SOC Dashboard**: Quick telemetry, MITRE ATT&CK coverage, live incident response metrics, and credential verification.
- **Detailed Threat Dossiers**: Deep-dive forensics with syntax-highlighted code, raw log evidence, IOC hashes, and SIEM correlation queries (Splunk SPL, Elastic KQL, Sigma).
- **Interactive Terminal**: CLI simulator supporting commands (`help`, `whoami`, `certs`, `skills`, `clear`).
- **Homelab & Detection Architecture**: Visual topology of ESXi/Proxmox virtualization, Wazuh/Splunk SIEM ingestion pipelines, and pfSense segmentation.
- **Automated GitHub Actions Deployment**: Continuous deployment directly to GitHub Pages on every push to `main`.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite + Tailwind CSS v4
- **Icons**: Lucide React
- **Typography**: JetBrains Mono + Geist
- **Deployment**: GitHub Pages via GitHub Actions

## 🚀 Quickstart & Local Development

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `git` installed on your machine

### 1. Clone & Install
```bash
git clone https://github.com/linhtat00/linhtat-portfolio.git
cd <YOUR_REPO_NAME>
npm install
```
